# Viva Questions

## 1. Why did you use Java?
Java provides strong OOP support, exception handling, collections, file I/O and multithreading.

## 2. Why no database?
This version is designed as a pure Core Java project. Text files provide persistent storage without external dependencies.

## 3. Where is inheritance used?
Student, Organizer and Admin inherit from User.

## 4. Where is encapsulation used?
Model fields are private and accessed using getters/setters.

## 5. Where is polymorphism used?
Student, Organizer and Admin override `toString()`.

## 6. Why use ArrayList?
It provides a dynamic collection for users, events and result lists.

## 7. What is synchronization?
Synchronization prevents multiple threads from modifying shared data at the same time.

## 8. What is a custom exception?
An exception class created by the programmer for application-specific errors.

## 9. Why use BufferedReader?
It efficiently reads text line by line.

## 10. Why use BufferedWriter?
It efficiently writes text data.

## 11. Where is multithreading used?
A background notification thread runs after successful registration.

## 12. What is method overriding?
A subclass provides its own implementation of a method inherited from its parent class.
