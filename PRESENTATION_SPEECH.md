# Presentation Speech

Good morning everyone.

Our project is the **College Event Management System**, developed completely using Core Java.

The main objective of our project is to simplify the management of college events and student registrations.

There are three main roles: Student, Organizer and Admin.

The organizer can create an event. The event initially remains pending. The admin can approve or reject it. Once approved, students can view the event and register for it.

The system also checks event capacity and prevents duplicate registrations.

We have used important Java concepts such as classes and objects, inheritance, encapsulation, method overriding, ArrayList, exception handling, file handling, multithreading and synchronization.

Instead of PostgreSQL or any external database, our pure Java version stores data in text files. This makes the project very easy to execute on any system having Java installed.

A background notification thread is also created after successful registration.

Overall, this project demonstrates how different Core Java concepts can be combined to solve a practical college problem.

Thank you.
