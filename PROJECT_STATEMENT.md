# Project Statement

## Title
College Event Management System

## Problem
Colleges conduct many technical, cultural, sports and academic events. Managing events and registrations manually can cause duplicate entries, capacity problems and difficulty tracking participants.

## Proposed Solution
The College Event Management System provides a menu-driven Core Java application for managing users, events, registrations and feedback.

## Main Users
1. Student
2. Organizer
3. Admin

## Main Functions
- Register/login
- Create events
- Approve/reject events
- View events
- Register for events
- Cancel registrations
- View participants
- Submit feedback

## Technology
Core Java, Java Collections, File I/O, Exception Handling and Multithreading.

## Database
No external database is used. Persistent data is stored in text files.
